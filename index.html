Camada de sensoriamento

Cada módulo pode ganhar olhos

Sensoriamento não é um módulo à parte — é uma camada que atravessa a plataforma. Onde faz sentido medir, existe um dispositivo ESP32 que alimenta o mesmo banco de dados que a gestão de manutenção usa.

Aguada — o sensoriamento que já está pronto

Rede de sensores ESP32 com protocolo ESP-NOW — sem dependência de Wi-Fi local. Gateway central transmite para o servidor. Dashboard web acessível de qualquer dispositivo.

Funciona como aplicação independente, para quem só precisa resolver o problema da água, e também como módulo integrado à plataforma, compartilhando ativos e ordens de serviço com os demais.

Como é construído

Software feito de dentro da operação

A plataforma não foi projetada a partir de um requisito de escritório. Nasceu dentro de uma rotina de manutenção real, onde a planilha já não dava conta e o sistema de prateleira não cabia no orçamento.

Fluxos que refletem a prática

Contratação por ata de registro de preços, fiscalização, certificação de execução, baixa de estoque. Não são etapas genéricas de um CMMS importado — são o processo que a equipe já executa, transposto para o sistema.

Construído junto com quem executa

Cada módulo foi validado por quem abre a ordem de serviço, quem fiscaliza e quem presta contas. Ajuste de fluxo chega em dias, não em ciclo de release trimestral.

Sem camada entre você e a engenharia

Suporte técnico direto com a equipe de desenvolvimento. Sem call center, sem triagem, sem ticket que envelhece na fila.
